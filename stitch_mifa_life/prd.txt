## 1. 🎯 Vision & Histoire du Projet

### 1.1 Origine
Mifa Life est un projet entrepreneurial collectif né d'une initiative de **11 étudiants maliens** réunis à Tokat, Turquie, sous le groupe **Mifa Life Tokat**. Partageant le même pays d'origine et le même désir d'entreprendre, ils ont décidé de transformer leur position géographique stratégique (à la croisée de la Chine et de la Turquie) en avantage compétitif pour créer une boutique en ligne au Mali.

### 1.2 Vision
> *"Connecter le Mali aux meilleurs produits du monde, à prix imbattables, livrés directement chez vous."*

**Mifa Life** — slogan : **"Vivez mieux, ensemble"** — est une plateforme e-commerce dropshipping qui met en relation les consommateurs maliens avec des fournisseurs sélectionnés en **Chine 🇨🇳** et en **Turquie 🇹🇷**, avec une livraison rapide et des paiements adaptés au Mali.

### 1.3 Modèle économique
Le modèle est basé sur le **dropshipping automatisé** :
1. Le client commande sur la plateforme Mifa Life
2. La commande est transmise **automatiquement** au fournisseur via API
3. Le fournisseur expédie directement (ou via transitaire) au Mali
4. Mifa Life perçoit la **marge** intégrée dans le prix affiché
5. L'équipe se concentre sur les **partenariats stratégiques** et la croissance

### 1.4 Ambition long terme
L'objectif est d'atteindre un **niveau d'automatisation maximal** : le site et l'application fonctionnent de manière autonome, libérant l'équipe pour se consacrer aux négociations fournisseurs, aux partenariats logistiques et au développement des marchés.

## 6. 🏗️ Architecture Technique

### 6.1 Stack Technologique

| Couche | Technologie | Justification |
|--------|-------------|---------------|
| **Frontend Web** | Next.js (React) | SSR pour SEO, dynamique, réutilisable pour mobile |
| **Application Mobile** | React Native | Partage de code avec Next.js, iOS + Android |
| **Backend** | Node.js + Fastify | Rapide, léger, idéal pour API REST & webhooks |
| **Base de données** | Supabase (PostgreSQL) | BDD relationnelle, Auth intégrée, Realtime, Storage |
| **Déploiement Frontend** | Vercel | Scalable, CI/CD intégré, gratuit au départ |
| **Déploiement Backend** | Railway / Render | Scalable, simple, adapté Node.js |
| **API Fournisseurs** | AliExpress API, 1688, APIs turques | Dropshipping automatisé |
| **Paiements** | PayDunya, Orange Money API, Wave API | Adapté au marché malien |

### 6.2 Architecture Système

```
┌─────────────────────────────────────────────┐
│         CLIENT (Browser / App Mobile)        │
└─────────────────┬───────────────────────────┘
                  │
┌─────────────────▼───────────────────────────┐
│        Next.js Frontend (Vercel)             │
└─────────────────┬───────────────────────────┘
                  │
┌─────────────────▼───────────────────────────┐
│         Fastify API Backend                  │
│    ┌──────────┐  ┌───────────────────┐       │
│    │ Auth     │  │ Order Engine      │       │
│    │ Products │  │ Auto-Dispatch API │       │
│    │ Payments │  │ Notifications     │       │
│    └──────────┘  └───────────────────┘       │
└────────┬─────────────────┬──────────────────┘
         │                 │
┌────────▼──────┐  ┌───────▼────────────────┐
│  Supabase DB  │  │  APIs Externes         │
│  (PostgreSQL  │  │  - Fournisseurs 🇨🇳🇹🇷  │
│  + Auth       │  │  - PayDunya / MoMo     │
│  + Storage)   │  │  - SMS / WhatsApp      │
└───────────────┘  └────────────────────────┘
```

### 6.3 Schéma Base de Données (Supabase)

**Tables principales :**
- `users` — clients et admins
- `products` — catalogue produits
- `product_variants` — variantes (taille, couleur, matière)
- `categories` — arbre de catégories
- `suppliers` — fournisseurs + configuration API
- `orders` — commandes clients
- `order_items` — lignes de commandes
- `supplier_orders` — commandes transmises aux fournisseurs
- `deliveries` — suivi livraisons
- `payments` — transactions
- `admin_roles` — rôles et permissions
- `notifications` — historique des notifications
